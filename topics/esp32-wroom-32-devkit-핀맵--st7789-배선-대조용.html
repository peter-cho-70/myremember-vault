ESP32-WROOM-32 DevKit 핀맵 — ST7789 배선 대조용

HARDWARE REFERENCE · ESP32-WROOM-32 DEVKIT (38-PIN)

ESP32-WROOM-32 DevKit 핀맵 가장 흔한 38핀 DevKit(예: DOIT ESP32 DEVKIT V1 계열) 실크스크린 기준입니다. 제조사마다 핀의 물리적 위치는 조금씩 다를 수 있지만, 배선에서 중요한 건 그게 아니라 핀 옆에 인쇄된 번호가 GPIO 번호와 일치하는지입니다 — 보드에서 18, 23, 5, 2, 4, 15 표기를 찾아 아래 배선표대로 연결하면 됩 니다. 아래 LCD 연결도는 ESP32와 2.25인치 ST7789 패널 사이의 8개 배선만 따로 뽑아 보여주고, 그 아래 전체 핀 다이어그램은 38핀 전체를 대조할 때 씁니다.

디버깅 메모

NOTE · 전압 강하 확인 NOTE · 스트래핑 핀 이번 세션에서 ESP32 3V3 핀은 3.3V였지만, LCD 쪽 GPIO0(BOOT), GPIO2(DC), GPIO12, GPIO15(BLK) VCC 핀은 2.8V로 측정됨 — 배선 구간 어딘가의 접촉 는 ESP32 부팅 시 특수한 역할을 하는 스트래핑 핀. 이 불량 가능성이 큼. 프로젝트는 GPIO2/15를 출력(DC/백라이트)으로만 쓰 이 다이어그램에서 각 핀을 하나씩 짚어가며 ESP32 핀 고 GPIO0은 보드 내장 BOOT 버튼 입력이라 정상 동작 → 중간 지점 → LCD 핀 순서로 재측정하면 전압이 정확 하지만, 보드가 부팅 자체를 안 하면 가장 먼저 의심할 히 어디서 떨어지는지 좁힐 수 있음. 대상. GPIO2는 다수 DevKit에서 온보드 파란 LED와 직결돼 있어, 화면과 무관하게 SPI 신호만으로도 LED가 반응할 수 있음(오작동 아님).

출처: examples/ST7789-225-Dashboard/pin_config.h 배선 정의 기준. 실제 보드가 30핀 변형이거나 실크스크린이 다 르게 인쇄돼 있다면, 위치보다 GPIO 번호 표기를 우선 신뢰할 것.
