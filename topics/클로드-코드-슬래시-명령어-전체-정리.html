★가장 먼저 알아야 할 핵심 명령어

100개가 넘는 명령어 중, 일상적으로 가장 자주 쓰게 되는 것들만 추렸습니다. 나머지는 필요할 때 찾아보면 됩니다.

/context

지금까지 쌓인 컨텍스트가 전체 대비 몇 %인지, 어디에 쓰였는지 색깔 그리드로 보여줌

/compact [지시문]

대화를 요약해 컨텍스트 공간을 확보. "무엇에 집중해서 요약할지" 지시 가능

/clear

프로젝트 메모리는 유지한 채 새 대화를 시작(별칭 /new, /reset)

/rewind

코드와 대화를 이전 시점으로 되돌리거나, 특정 지점부터 요약. 실수했을 때 구원투수

/model [모델명]

사용할 모델을 바꾸고 기본값으로 저장. 화살표로 추론 강도(effort)도 조절 가능

/effort [단계]

추론에 얼마나 공을 들일지 설정 (low/medium/high/xhigh/max)

/permissions

어떤 도구·명령을 허용/거부할지 규칙 관리 (별칭 /allowed-tools)

/plan [설명]

큰 변경 전에 플랜 모드로 들어가 먼저 계획부터 세움

/init

프로젝트를 위한 CLAUDE.md 가이드 파일을 처음 생성

/memory

CLAUDE.md 메모리 파일을 편집하고 자동 메모리 항목을 확인

/mcp

연결된 MCP 서버 관리 및 OAuth 인증 처리

/diff

지금까지의 변경사항(git diff)과 턴별 변경 내역을 인터랙티브하게 확인

/code-review [--fix]

현재 diff에서 버그·정리 포인트를 검토. --fix로 바로 적용 가능

/security-review

브랜치 변경분을 보안 취약점 관점에서 검토(인젝션, 인증 문제, 데이터 노출 등)

/usage

세션 비용, 플랜 사용량, 스킬/서브에이전트/MCP별 사용 내역 확인 (별칭 /cost, /stats)

/tasks

백그라운드에서 돌고 있는 작업(서브에이전트 포함) 목록 확인 (별칭 /bashes)

/doctor

설치·설정 문제를 진단하고 필요하면 자동으로 고쳐줌

/resume [세션]

이전 대화를 이어서 재개하거나 세션 선택 화면을 염 (별칭 /continue)

/help

도움말과 사용 가능한 명령어 목록 표시

/btw [질문]

대화 기록에 남기지 않고 곁다리 질문만 던지고 답을 받음

1컨텍스트 · 메모리 관리

명령어 설명
★ /context [all] 현재 컨텍스트 사용량을 색깔 그리드로 시각화. 어떤 도구·메모리가 공간을 많이 차지하는지, 한도 초과 시 얼마나 넘었는지도 알려줌. all을 붙이면 항목별 상세 내역까지 펼쳐 보여줌
★ /compact [지시문] 대화 내용을 요약해서 컨텍스트 공간을 비움. 예: /compact focus on the auth bug fix
/autocompact [auto|토큰수] 자동 압축이 시작되는 시점(컨텍스트가 얼마나 찼을 때)을 설정. 500k처럼 토큰 수 지정 가능
★ /clear [이름] 프로젝트 메모리는 유지한 채 컨텍스트를 비우고 새 대화 시작. 별칭: /reset, /new
★ /rewind 코드와 대화를 체크포인트로 되돌리거나 특정 지점부터 요약. 별칭: /checkpoint, /undo
★ /memory CLAUDE.md 메모리 파일 편집, 자동 메모리(auto-memory) 켜기/끄기 및 조회
/export [파일명] 현재 대화를 텍스트로 내보내기. 파일명을 주면 바로 저장, 없으면 클립보드 복사/저장 선택창
/recap 현재 세션 내용을 한 줄로 즉시 요약
/copy [N] 마지막 답변을 클립보드로 복사. 숫자를 주면 N번째 이전 답변 복사
/btw [질문] 대화 기록에 남기지 않는 곁다리 질문(side question)

2모델 · 성능 설정

명령어 설명
★ /model [모델명] AI 모델 변경 및 기본값 저장. 인자 없이 실행하면 선택 화면이 열림
★ /effort [단계|auto] 추론 강도 설정: low/medium/high/xhigh/max/ultracode. auto는 모델 기본값으로 복귀
/fast [on|off] 빠른 응답을 위한 fast 모드 토글
/advisor [model|off] 중요한 순간에 두 번째 모델의 조언을 받는 어드바이저 기능 켜기/끄기
/config [key=value] 테마, 모델, 출력 스타일 등 환경설정 화면. 값을 직접 지정도 가능(예: /config theme=dark). 별칭: /settings
/goal [조건|clear] 목표를 설정하면 그 조건이 충족될 때까지 여러 턴에 걸쳐 계속 작업

3코드 리뷰 · 검증

명령어 설명
★ /diff 커밋 전 변경사항과 턴별 변경 내역을 보여주는 인터랙티브 뷰어
★ /code-review [단계] [--fix] 현재 diff에서 버그·정리 포인트를 검토. --fix로 적용, --comment로 GitHub PR에 코멘트, ultra로 클라우드 심층 리뷰
/review [PR번호] GitHub PR을 빠르게 한 번만 훑는 읽기 전용 리뷰
★ /security-review 현재 브랜치 변경분을 보안 취약점(인젝션, 인증, 데이터 노출 등) 관점에서 검토
/simplify [대상] 변경된 코드를 정리 관점(재사용, 단순화, 효율성, 추상화 수준)에서 병렬 리뷰 후 적용
/verify 실제로 앱을 실행해서 변경사항이 의도대로 동작하는지 확인 (테스트에만 의존하지 않음)
/run 프로젝트 앱을 실행해서 변화를 직접 확인
/run-skill-generator /run, /verify가 프로젝트를 어떻게 실행할지 학습하도록 전용 스킬을 생성
/ultrareview [PR|브랜치] 클라우드 샌드박스에서 여러 에이전트가 함께하는 심층 리뷰. 지금은 /code-review ultra가 권장 방식

4병렬 작업 · 백그라운드 세션

명령어 설명
★ /tasks 현재 세션의 백그라운드 작업(완료된 서브에이전트 포함) 목록. 별칭: /bashes
/background [prompt] 현재 세션을 백그라운드 에이전트로 분리해 터미널을 자유롭게 함. 별칭: /bg
/batch 큰 규모 변경을 5~30개 독립 단위로 쪼개, 각각 별도 워크트리에서 병렬로 서브에이전트가 처리하고 PR까지 생성
/branch [이름] 지금 시점에서 대화를 분기해 다른 방향을 시도. 원본은 /resume으로 복귀 가능
/fork [prompt] 현재 대화를 통째로 복사해 새 백그라운드 세션으로 분리(원본은 계속 진행)
/subtask 백그라운드 서브에이전트에게 작업을 맡기고, 끝나면 결과가 현재 대화로 돌아옴
/loop [간격] [prompt] 세션을 열어둔 채 정해진 간격으로 프롬프트를 반복 실행. 별칭: /proactive
/workflows 실행 중이거나 완료된 워크플로 진행 상황을 보고 관리
/stop 백그라운드 세션에 붙어있는 상태에서 그 세션을 완전히 중지

5세션 전환 · 이어하기

명령어 설명
★ /resume [세션] ID나 이름으로 이전 대화를 재개, 또는 세션 선택 화면. 별칭: /continue
/rename [이름] 현재 세션 이름 변경. 없으면 대화 내용으로 자동 생성
/status 버전, 모델, 계정, 연결 상태를 보여주는 상태 탭
/teleport Claude Code 웹(클라우드) 세션을 터미널로 가져오기. 별칭: /tp
/remote-control claude.ai에서 이 세션을 원격으로 이어갈 수 있게 함. 별칭: /rc
/desktop 현재 세션을 Claude Code 데스크톱 앱에서 이어서 진행. 별칭: /app
/cd 세션의 작업 디렉터리를 변경(프롬프트 캐시는 유지)
/add-dir 현재 세션에서 접근 가능한 작업 디렉터리를 추가
/exit CLI 종료. 백그라운드 세션에 붙어있었다면 세션은 계속 실행되며 분리만 됨. 별칭: /quit

6권한 · 외부 연동 설정

명령어 설명
★ /permissions 도구 사용에 대한 허용/확인/거부 규칙 관리. 별칭: /allowed-tools
★ /mcp [reconnect|enable|disable] MCP 서버 연결과 OAuth 인증 관리
/hooks 도구 이벤트에 걸린 훅(hook) 설정 보기
/plugin [하위명령] 플러그인 설치/활성화/비활성화 등 관리
/reload-plugins [--force] 재시작 없이 활성 플러그인을 다시 불러옴
/reload-skills 세션 중 추가·변경된 스킬을 재스캔
/skills 사용 가능한 스킬 목록 확인 및 필터링
/agents 서브에이전트 생성·관리 안내(직접 .claude/agents/ 편집 권장)
/chrome Claude in Chrome 설정 구성
/install-github-app GitHub 저장소에 Claude GitHub 앱 설치
/install-slack-app Claude Slack 앱 설치(OAuth 플로우)
/web-setup 로컬 gh CLI 인증으로 GitHub 계정을 Claude Code 웹에 연결
/claude-api [subcommand] Claude API/Managed Agents 참고자료 로드, 모델 마이그레이션, 프롬프트 감사 등
/design-sync [hint] 리포의 React 디자인 시스템을 Claude Design에 업로드
/design-login /design-sync를 위한 claude.ai 계정 인가
/autofix-pr [prompt] 현재 브랜치의 PR을 지켜보며 CI 실패나 리뷰 코멘트에 자동으로 수정 제안
/schedule [설명] 클라우드에서 실행되는 루틴(정기 작업) 생성/관리. 별칭: /routines
/fewer-permission-prompts 자주 쓰는 읽기 전용 명령을 분석해 허용 목록에 자동 추가

7사용량 · 계정 · 결제

명령어 설명
★ /usage 세션 비용, 플랜 사용 한도, 스킬/서브에이전트/플러그인/MCP별 사용 내역. 별칭: /cost, /stats
/usage-credits 사용 한도에 도달했을 때 크레딧 설정 또는 관리자에게 요청
/upgrade 더 높은 플랜으로 업그레이드하는 페이지 열기
/login Anthropic 계정 로그인
/logout Anthropic 계정 로그아웃
/privacy-settings 개인정보 설정 확인 및 변경 (Pro/Max 전용)
/passes Claude Code 무료 이용권을 친구에게 공유(자격이 있는 경우만 표시)

8진단 · 도움말 · 피드백

명령어 설명
★ /help 도움말과 사용 가능한 명령어 표시
★ /doctor 설치·설정 문제를 진단하고 고침(별칭 /checkup). 오래된 CLAUDE.md 정리, 느린 훅 감지 등도 수행
/debug [설명] 디버그 로깅을 켜고 세션 로그를 분석해 문제를 진단
/bug [report] 버그 신고 또는 대화 공유(별칭 /share)
/feedback [report] 제품에 대한 일반 피드백 전송
/heapdump 메모리 사용량 진단용 힙 스냅샷 생성(전체 대화가 포함되므로 공유 시 주의)
/release-notes 버전별 변경사항(체인지로그) 확인
/insights 프로젝트 영역, 작업 패턴, 마찰 지점을 분석한 리포트 생성
/team-onboarding 최근 30일 사용 이력을 바탕으로 팀 온보딩 가이드 생성
/powerup 애니메이션 데모로 Claude Code 기능을 짧게 익히는 튜토리얼
/deep-research 여러 웹 검색을 병렬로 수행하고 출처를 검증해 리포트로 종합(워크플로)
/dataviz [요청] 차트·대시보드 디자인 가이드(색상, 접근성 등)를 적용해 시각화 제작

9UI · 환경설정 · 기타

/statusline 화면 하단 상태줄 구성

/focus 마지막 프롬프트와 결과만 보여주는 포커스 뷰 토글
/ide IDE 연동 관리 및 상태 표시
/sandbox 샌드박스 모드 토글(지원 플랫폼에 한함)
/voice [hold|tap|off] 음성 받아쓰기 켜기/끄기
/mobile Claude 모바일 앱 다운로드 QR코드 표시(별칭 /ios, /android)
/remote-env 클라우드 에이전트의 기본 실행 환경 선택
/setup-bedrock Amazon Bedrock 인증·리전·모델 설정 마법사

/radio Claude FM 로파이 라디오 브라우저로 열기

10폐지/변경된 명령어

과거 버전에 있었지만 지금은 제거되었거나 다른 명령어로 대체된 것들입니다. 화면에 안 보여도 정상입니다.

명령어 현재 상태
/vim v2.1.92에서 제거. /config → Editor mode에서 Vim/Normal 전환
/pr-comments v2.1.91에서 제거. 그냥 Claude에게 PR 코멘트를 보여달라고 요청하면 됨
/ultraplan 제거됨. 대신 플랜 모드(/plan) 사용 권장

참고 모든 명령어가 모든 사용자에게 보이는 것은 아닙니다. 플랫폼, 요금제, 실행 환경에 따라 달라집니다. 예를 들어 /desktop은 macOS·Windows에서 구독 로그인 상태일 때만, /upgrade는 Enterprise 플랜에서는 보이지 않습니다.

MCP 프롬프트 연결된 MCP 서버가 자체적으로 제공하는 프롬프트는 /mcp__서버명__프롬프트명 형태로 명령어처럼 나타날 수 있습니다.

Claude Code 공식 문서(code.claude.com/docs/en/commands) 기준, 2026년 8월 확인. 버전 업데이트에 따라 명령어 목록과 동작은 달라질 수 있습니다.
